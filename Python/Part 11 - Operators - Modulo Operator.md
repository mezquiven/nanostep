We can use % to get the remainder of a division.
How many 3 are in 21? There are seven 3. The remainder is zero.
```python
num1 = 21
num2 = 3

print("The first result is: ", num1 / num2)
print("The second result is: ", num1 % num2)
```
How many 10 are in 107? The answer is 10. So the remainder is 7.
```python
num1 = 107
num2 = 10

print("The first result is: ", num1 / num2)
print("The second result is: ", num1 % num2)
```
