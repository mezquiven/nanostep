The >= symbol is used to compare if the first value is higher value than the second value. It will also check if both values are equal.
```python
value1 = 7892
value2 = 7892

print(value1 >= value2)
```

The condition is false so print function won't execute.
```python
value1 = 16
value2 = 64

if value1 >= value2:
    print("The first variable was compared to the second variable.")
```
