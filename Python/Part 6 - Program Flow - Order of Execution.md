When running a program, we can think of the program flow as a waterfall. Lines are executed one after another from top to bottom. One at a time.

The program flow can be manipulated by using if, if else, else if, loops and other statements like break, continue, etc.

Program flow can become complicated when multitasking is added. Multitasking is where we can start a task and it will run together with our main program at the same time.

Program flow can also be manipulated when functions are called.
