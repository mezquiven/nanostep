To add a comment to a line, use the # symbol, followed by a message that describes the code.

```python
# display a message
print("My name is Migrand.")
```

Another way to use a single-line comment is by adding it at the end of a code.
```python
print("The weather forecast for today is not looking good.") # display a string
```

Multi-line comments can be added by using three ", followed by the string inside as comment and then closed by three ".
```python
"""
    find the average value and store it in the result variable
    by using the five float data type variables
    and then display the value of result
"""

result = 0
num1 = 23.75, num2 = 52.92, num3 = 87.22, num4 = 84.98, num5 = 17.67

add_the_five_numbers = num1 + num2 + num3 + num4 + num5
result = add_the_five_numbers / 5

print(`The result is: {result}`)
```
