Variable names can't start with a number or special characters. Using a space will also result to an error. Reserved keywords that are used as part of the syntax in a specific programming language can't be used as variable names. There are some other characters that can be used in variable names like _.

Variable names that are not allowed:
- `3number`
- `full name`
- `def`

Using _ as the first character of the variable name means that you intend to only use it internally.

Variable names that are allowed:
- `numb3r`
- `player_health`
- `_age`

Variable names are case sensitive and using an uppercase letter as the first character in a variable name is a different variable to a name that only uses lowercase letters.

`customer` is a different variable name when compared to `Customer`.
