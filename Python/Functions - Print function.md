We can use the print function to display a message to the user.
```python
print("One nanostep forward is better than no step at all.")
```

We can put the value inside a variable which will make the code readable
```python
message = "Experimenting with a programming language is very fun."
print(message)
```

There are other ways of using print like by separating variables
```python
name = "Migrand"
level = 206

print(name, "owns a character with a level of", level, "in a game.")
```

Using the + symbol can make integer data type variables be displayed as strings.
```python
result = 46 - 24
print("The result of the computation is: " + result)
```

Tilde ` and curly braces {} can be combined to have a more readable code.
```python
number = 92
current = 91
print(`The customer being served now is number {current} and the next customer in queue is number {number}`)
```
