
Assigning a value to a variable declares it.

```python
player_health = 100
```

We can only use the variable after we have declared it.

```python
number = 8

print("The value is: ", number)
```

We can modify the value inside a variable or use the variable in calculations.

```python
money = 300
money = money + 78

print("The value is: ", money)
```
