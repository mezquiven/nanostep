We can use + to combine two values.
```python
print("The value is: " + 897)
```

The integer data type 897 value will be combined with the string and the result is a string data type. This is a concatenation or combining of two strings. Since there is one string inside the print function, the + symbol will concatenate the value 897 to the string.

We will see that one string and one integer with the + symbol is different to two integers with +.
```python
value1 = "9152"
value2 = 4

print(value1 + value2)
```

Two intergers with + is a computation.
```python
value1 = 9152
value2 = 4

print(value1 + value2)
```
