Use * to multiply two values in computations.
```python
value1 = 3
value2 = 7

print(value1 * value2)
```

We can also use * to multiply the variable to itself one time or more.
```python
value1 = 6

print("The square is: ", value1 * value1)
```

If * is used on strings, it will be repeated.
```python
print("Don't put anything inside the air fryer when preheating or it will go burn into the heating element" * 3)
```
